# Presentation authoring

Prepare the complete booked lesson with a realistic45/90/135-minute agenda. Include reading, thinking and discussion; the presentation is learner-paced. Reuse short coherent learning activities within it. An optional remediation/stretch activity says which core activity it replaces.

Teach meaning, why and then method. Use one new idea and mathematical action per screen, with a concrete example before naming a rule. Prefer interactive models and staged reasoning to bullets. Keep student text short and spoken Hebrew natural. Age-appropriate playfulness must not change the website logo, palette or Heebo typography.

Every instructional stage has private notes: time, natural explanation, question, expected understanding, plausible misconception, concrete help, transition and source where relevant. Notes must refer to actual numbers and support teaching rather than repeat the slide. Projection/learner JSON never includes notes or answer keys.

Official-question flow: read/mark givens → choose a method → attempt → staged solution → check units/domain/context. Preserve the source original; keep annotations/solutions separate. Show required target stimuli during independent tasks while withholding solutions. Render and inspect mobile, RTL, maths, print and reduced-motion output.

For derived numeric visuals, author question-only TeX for independent practice; preserve the given diagram and withhold computed formulas in screen, print and video. A one-frame independent question cannot double as a worked explanation. Check exported pages visually for orphaned titles, clipped mathematics and paper-wasting page breaks.

Every new function and interval must be defined in learner-visible content before use; private presenter notes cannot hold the only givens. Controlled diagrams display their actual capabilities: geometry shape8 is a triangle, not three attached squares. Use staged typeset steps for calculations the diagram does not animate. Parabola a describes vertical scaling; do not equate it with the horizontal width factor. V2 exploration offers a,h,k, including half-step a changes.
