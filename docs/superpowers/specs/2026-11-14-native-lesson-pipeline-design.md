# Booking to native learning bundle

Continue the owner's approved living learning CRM. The personal Google connection
and fresh native workspace are already deployed. Legacy authoring stays disabled.
A booking must durably enqueue one preparation job, scoped by student ID and
booking ID, without delaying or failing booking. A restart recovers queued work;
replayed bookings do not duplicate material. Cancellation suppresses publication.

A bundle owns a native Google Slides presentation, a private Google Docs tutor
brief/notes and solutions, a student homework document, and links to interactive
activities using the existing mathematical/game runtime. Drive is artifact
storage; SQLite holds job identity/retry state and operational bookings/progress.
Sheets contains linked learner, lesson, material and assignment records. Do not
turn a file view into a mastery claim. Preserve human edits, old versions and all
customer history. No public sharing, notifications or student release during the
initial rollout. Draft creation and quality review are separate from delivery.

First prove the existing normal-distribution calibration lesson (90 minutes,
35372, school s convention) through native Slides/Docs with its verified official
question, original site branding, diagrams, progressive explanation and teacher
notes. This is a synthetic review bundle, not a generic all-level approved engine.
For unsupported educational contexts, create a tutor-visible needs-preparation
job rather than generating a guessed or inappropriate lesson. Do not publish old
HTML or screenshots under a native Slides name. Editable narrative text is native;
mathematical illustrations/equations can be image assets when needed. Preserve
assessment givens and hide solutions from student artifacts. Reuse the approved
composition policy; do not resume the rejected bullet-only renderer.

A reliable end-to-end draft path and reviewable first bundle precede activation
of automatic student delivery. Future generic authoring must carry explicit grade,
subject, duration, readiness and source context, and must pass teaching review.
