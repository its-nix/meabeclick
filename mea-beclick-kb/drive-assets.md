## Privacy boundary

**This repository is public.** The Drive parent contains a separately shared Tutoring subtree with student and teaching records. **Never put a child-folder link, raw student or family information, payment information, personal contacts, private client documents, credential values or access tokens into this repository or the company KB.** The private `mea-beclick-kb/students/` and `mea-beclick-kb/pricing/` paths remain untracked/local and are not to be read, imported or synchronized.

The linked parent folder is access-controlled; this public pointer does not grant access and must not be used as a request to broaden Drive sharing.

## Handoff rule

- Maintain the canonical product decision in [PRODUCT.md](../PRODUCT.md), not a second Google Doc.
- Put original ad creatives, business media and other supporting assets in the appropriate restricted Drive location, keeping existing sharing intact.
- When a business asset informs a product change, contribute a **sanitized** GitHub note/PR that cites only safe, authorized evidence; include a direct Drive file link **only if the linked document is explicitly suitable for public disclosure**.
- Send reusable, all-org-safe lessons to the private company KB by link, not by copying student records or product truth.
- After changing an asset's location, verify the destination and update the owning navigation pointer. There is no automatic two-way sync.

This page does not alter tutor, family, database, price or product authorization behavior.
